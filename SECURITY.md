# Signaler un problème de sécurité

La version `0.1.0-dev.0` est une démonstration locale sur données synthétiques. Elle ne peut pas héberger un coffre familial ni être exposée comme un service authentifié. Voir le [périmètre et les mesures de sécurité](docs/security.md). Aucune version de Production n'est proposée ; l'examen des signalements porte sur le code courant de `main`.

Pour une vulnérabilité sensible, utiliser le [signalement privé GitHub](https://github.com/JeanZay/hestia/security/advisories/new). Si ce canal est indisponible, ne pas publier les détails d'exploitation dans une Issue publique pour le contourner.

Fournir le commit ou la version concernée, l'impact observé et les étapes de reproduction avec des données synthétiques. Ne joindre aucun document personnel, secret, jeton ou identifiant d'une instance, y compris dans un signalement privé.

Les [Issues publiques](https://github.com/JeanZay/hestia/issues) conviennent aux anomalies ordinaires qui ne révèlent pas de vulnérabilité sensible. Le projet ne s'engage sur aucun délai de réponse ou de correction.
