# Signaler un problème de sécurité

Cette version est une démonstration locale sur données synthétiques. Elle ne peut pas héberger un coffre familial ni être exposée comme un service authentifié. Voir le [périmètre et les mesures de sécurité](docs/security.md).

Ne joignez aucun document personnel, secret ou identifiant d'une instance dans une Issue publique. Décrivez un problème à l'aide d'un cas synthétique reproductible.

Aucun dépôt distant ni canal de signalement privé n'existe encore. Avant publication, le responsable activera un canal privé de signalement et indiquera ici son adresse vérifiée ainsi que les versions maintenues. Aucun contact ni engagement de délai de réponse n'est inventé dans cette fondation. Une vulnérabilité sensible attend ce canal privé ; elle ne doit pas être publiée pour contourner son absence.
